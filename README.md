# QA-portfolio
Portfólio de estudos e projetos práticos em Quality Assurance e Testes de Software.

Este repositório acompanha minha evolução na área de QA,
reunindo exercícios, documentação de testes, casos de teste,
registro de defeitos, evidências e projetos práticos.

## Conteúdos

- Fundamentos de testes
- Cenários e casos de teste
- Técnicas de projeto de teste
- Testes de regressão, sanity e smoke
- Documentação de testes
- Registro e acompanhamento de defeitos
- Evidências de testes
- Análise de problemas
- Indicadores de qualidade
- Melhoria contínua

## Em desenvolvimento

Este portfólio será atualizado conforme avanço nos estudos
e projetos práticos de QA.
